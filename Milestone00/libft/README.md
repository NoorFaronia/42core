# Libft

**Libft** is a custom C library built as part of the 42 school curriculum.  
The goal is to reimplement standard C library functions and develop a deeper understanding of memory management, strings, and basic data handling in C.

---

✅ This project was completed with a **100/100** score.

---

## Features

This project is split into two main parts:

### 📌 Part 1: Standard C Functions

Reimplementations of libc functions such as:

- Memory: `ft_memset`, `ft_bzero`, `ft_memcpy`, `ft_memmove`, `ft_calloc`, `ft_memchr`, `ft_memcmp`  
- Strings: `ft_strlen`, `ft_strchr`, `ft_strrchr`, `ft_strlcpy`, `ft_strlcat`, `ft_strncmp`, `ft_strnstr`, `ft_strdup`  
- Character checks: `ft_isalpha`, `ft_isdigit`, `ft_isalnum`, `ft_isascii`, `ft_isprint`, `ft_toupper`, `ft_tolower`  
- Conversions: `ft_atoi`

---

### 🛠️ Part 2: Utility Functions

Additional useful functions:

- Strings: `ft_substr`, `ft_strjoin`, `ft_strtrim`, `ft_split`
- Conversions: `ft_itoa`
- Output: `ft_putchar_fd`, `ft_putstr_fd`, `ft_putendl_fd`, `ft_putnbr_fd`
- Function mapping: `ft_strmapi`, `ft_striteri`

---

## 📁 File Structure

- libft.h — Header file with all function declarations.
- *.c — Source files for each implemented function.
- Makefile — Used to compile and generate libft.a.
